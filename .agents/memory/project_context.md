# Project Context: GameTracker

## 1. Product Vision
**GameTracker** — современное Android-приложение для геймеров:
- **Поиск и каталог игр**: поиск по ключевым словам, фильтрация по жанрам, платформам и рейтингу.
- **Локальная библиотека пользователя**: статусы ("Играю", "Пройдено", "Хочу поиграть", "Заброшено"), оценка, пользовательские заметки.
- **Персонализированные рекомендации**: подборки на основе любимых жанров и истории библиотеки.
- **Календарь релизов и уведомления**: трекинг будущих релизов с уведомлениями.

## 2. IGDB API & Ktor BFF Architecture
- IGDB (Twitch Developer Portal) требует `Client-ID` и `Client-Secret` (OAuth2 token generation), которые **категорически запрещено** зашивать в мобильное клиентское приложение (их легко извлечь декомпиляцией APK/AAB).
- Для безопасной и эффективной работы используется паттерн **BFF (Backend for Frontend)** на Kotlin/Ktor (каталог `backend/` в репозитории).
- **Задачи BFF:**
  1. Хранение секретов IGDB и автоматическое обновление OAuth2 токенов.
  2. Агрегация и трансформация тяжелых ответов IGDB в легковесные DTO под нужды мобильного UI.
  3. Кеширование частых запросов (популярные игры, жанры).
- **Сборки приложения:**
  - `demo`: использует локальные моки/фикстуры (не требует запущенного бэкенда при разработке или проверке рекрутером/ревьюером).
  - `live`: обращается к Ktor BFF через Retrofit. Для локального эмулятора base URL по умолчанию `http://10.0.2.2:8080/`, настраивается через `local.properties` (`bff.baseUrl`).
